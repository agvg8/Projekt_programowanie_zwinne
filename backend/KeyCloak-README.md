# Instrukcja jak zrobić, żeby keycloak wam działał.
## Podstawy:
UWAGA niniejsza instrukcja jest kompatybilna z KeyCloak w wersji 26.4.0. 
1. zainstaluj i uruchom keycloak
2. zaloguj sie na panel administratora (http://localhost:8080)
3. w panelu po lewej klikacie `manage realms` -> `create realm`
4. dodajecie plik `programowanie-zwinne-realmg.json` i nazywacie to `programowanie-zwinne`
